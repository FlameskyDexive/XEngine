# Controls Gallery

Minimal first-party XGUI gallery. The template creates:

1. Canvas
2. Sliced Image panel
3. Wrapped Text
4. Button with a label
5. InputField with placeholder
6. Horizontal layout row of three labeled chips

Instantiate `XGuiControlsGallery.xgui-template.json` inside an open project. After spawn, select the Canvas and enter Play Mode to click the Button and type into the InputField.
