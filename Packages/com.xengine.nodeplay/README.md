# NodePlay

Visual behaviour graphs for XEngine: **reactive behaviour trees**, **hierarchical state
machines**, and **multi-actor dialogue trees** on one shared node-graph core (blackboards,
tasks, subgraph nesting, runtime debug visualization).

## Status

`0.1.0` — package skeleton. Runtime data model, editor graph window, and the three graph
modules land milestone by milestone; see `Documentation~/index.md` for the current surface
and `CHANGELOG.md` for progress.
