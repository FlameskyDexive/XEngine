# 2D Common

Shared 2D types, sorting, and utilities used by Sprite, Tilemap, and Pixel Perfect.

This package stays built-in (`installByDefault` omitted) and auto-mounts with the Editor. Install
`com.xengine.feature.2d` to also pull optional 2D workflow packages (Animation, Tilemap, importers).

Runtime Sprite, Renderer2D, PixelPerfectCamera, and Physics2D stay in `XEngine.Runtime`. This
package adds the optional workflow layer on top of that core.
