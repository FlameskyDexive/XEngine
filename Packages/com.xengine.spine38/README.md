# Spine 3.8 for XEngine

Esoteric Spine **3.8** runtime. Install from Package Manager. **Cannot be installed together with `com.xengine.spine` (4.x).**

Each user must hold a [Spine Editor license](https://esotericsoftware.com/spine-purchase).

Adapter (`XEngine.Spine38`) is MIT. Vendored `spine-csharp` 3.8 and sample assets stay under the [Spine Runtimes License](https://esotericsoftware.com/spine-runtimes-license).

Export from Spine Editor 3.8.xx. Do **not** use export version `3.8.75` (rejected by the official runtime). `4.x` JSON is rejected by this package's importer.
