# Spine 3.8 Getting Started

Import this sample from Package Manager after installing `com.xengine.spine38`.

Assign the imported `spineboy-ess` SkeletonDataAsset on each `SkeletonAnimation` / `SkeletonGraphic`.

| Scene | What it shows |
|-------|----------------|
| 1 The Spine GameObject | Spineboy walk loop |
| 2 Controlling Animation | walk → jump → walk via `SetAnimation` / `AddAnimation` |
| 3 SkeletonGraphic | xgui `SkeletonGraphic` idle/walk |

Requires a Spine Editor license to ship products that include these runtimes.
