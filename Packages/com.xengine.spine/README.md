# Spine

Official optional XEngine package. It ships with the Editor but is **not** added to a project until you install it from Package Manager (`Window / Package Management / Package Manager`).

Installing copies this folder into the project's `Library/PackageCache/com.xengine.spine@<version>/` and records the pin in `Packages/manifest.json`.

**License:** each user of this package must hold their own [Spine Editor license](https://esotericsoftware.com/spine-purchase). The XEngine adapter is MIT. Vendored `spine-csharp` and official sample assets remain under the Spine Runtimes License.
