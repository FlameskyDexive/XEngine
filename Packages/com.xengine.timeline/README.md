# Timeline (com.xengine.timeline)

Cutscene / sequence editor for XEngine, built on the engine's PlayableGraph runtime. Provides a
`PlayableDirector` component that drives a `PlayableGraph` (with a `ManualClock` for scrubbing) from a
`TimelineAsset`, plus the track types and a dockable Director window.

See `docs/2026-08-11-AnimationModule.md` (milestones M10–M14) for the design.
